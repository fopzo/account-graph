# 📊 Standoff 2 Accounts Graph

Graph of Standoff 2 account registrations, rendered with **Recharts**.

Data source: `account_graph.csv` · **1 row = 50 000 accounts**

---

### Features
- 📈 Registrations chart (bar / line / area)
- 🗓 Group by month or year
- 🔎 Filter by year range
- ➕ Cumulative mode
